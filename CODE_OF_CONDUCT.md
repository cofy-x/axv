# AXV Code of Conduct

The [cofy-x Code of Conduct](https://github.com/cofy-x/.github/blob/main/CODE_OF_CONDUCT.md) applies to participation in AXV. This page supplies this repository's reporting channels under that policy.

Report sensitive conduct incidents through [AXV's private reporting form](https://github.com/cofy-x/axv/security/advisories/new). This uses GitHub's private Security Advisories channel, as provided by the organization's enforcement policy. Identify the report as a conduct concern and include only relevant context; do not share live credentials or post sensitive details publicly.

For non-sensitive conduct concerns, use the public channels in [Support](SUPPORT.md). Suspected vulnerabilities follow the [Security policy](SECURITY.md).
